Popup origin check (POCD)

MSAL automatically sends pocd=1 when its origin check passes. Otherwise it omits the parameter so Entra keeps COOP enforcement. This app uses the default redirect bridge in both cases.

Open this page directly for the trusted top-level case, or use the cross-origin launcher to give this app an untrusted opener.

In a fresh browser session, prompt=none should return login_required without caching tokens.
