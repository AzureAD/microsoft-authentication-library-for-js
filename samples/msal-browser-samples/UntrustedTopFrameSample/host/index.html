Untrusted Host Application This app does NOT use MSAL and never sees tokens.
Untrusted Top Frame Sample — this untrusted host runs on localhost:3000 and embeds a trusted first-party app from localhost:3001 in the iframe below. When you sign in, the iframe calls acquireTokenPopup, which opens a top-level popup-relay page on its own origin that relays a single-use, PKCE-bound authorization code (never a token) back to the iframe, where MSAL completes the token exchange. The host is never part of the auth flow.
