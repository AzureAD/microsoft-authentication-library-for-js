🐛 MSAL Browser - Empty Environment Bug Reproduction

⚠️ Setup Required

Before testing:

  1. Create a .env file (copy from .env.example) and add your Azure AD application client ID
  2. Ensure your redirect URI includes http://localhost:8080
  3. You must be signed in to see the bug (run Test 1 first if needed)

🎯 What This Reproduces

Bug: MSAL Browser occasionally creates accounts with environment: "" (empty string)

Impact: Causes authority_mismatch errors on subsequent token requests

Root Cause: Race condition during authority metadata resolution allows getPreferredCache() to return empty string
