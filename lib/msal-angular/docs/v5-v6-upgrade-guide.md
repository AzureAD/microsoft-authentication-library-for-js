# Upgrading from MSAL Angular v5 to v6

MSAL Angular v6 requires a minimum version of Angular 21 and is dropping support for Angular 19 and 20.

Please see the [MSAL Browser migration guides](https://github.com/AzureAD/microsoft-authentication-library-for-js/tree/dev/lib/msal-browser/docs) for browser support and other key changes.

## Breaking changes in `@azure/msal-angular@6`

### Minimum Angular version is now 21

`@azure/msal-angular@6` requires Angular `^21.0.0` or higher. Applications still on Angular 19 or 20 should remain on `@azure/msal-angular@5` until they are ready to upgrade Angular. Follow the [Angular Update Guide](https://angular.dev/update-guide) to migrate your application to Angular 21.
